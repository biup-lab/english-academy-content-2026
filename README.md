# 2026 초등 영어학원 연간 콘텐츠 전략

학부모 1,500건의 질문에서 찾은 월별 블로그 콘텐츠 전략 랜딩페이지.

## 파일 구성
- `index.html` — 페이지 본문
- `styles.css` — 디자인
- `data.js` — 월별 콘텐츠 124선 데이터
- `landing.js` — 차트·월별 캘린더 동작

## GitHub Pages로 공개하기
1. 이 폴더의 파일 전체를 저장소 루트에 올립니다.
2. 저장소 **Settings → Pages → Branch: main / (root)** 선택 후 저장.
3. 잠시 후 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다.
